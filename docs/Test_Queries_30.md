# CCOP Text-to-Cypher 수동 테스트용 문항 (v3.4 기준)

웹 UI 검색창에 아래 문항들을 그대로 복사해서 하나씩 붙여넣은 뒤, AI가 얼마나 정확하게 쿼리를 짜고 그래프를 찾아주는지 직접 테스트해 보세요!

---

## [1단계] 기초 단일 노드 및 속성 검색 (Basic)
1. 이름이 '피의자1'인 사람(vt_psn) 노드를 모두 찾아줘.
2. 계좌번호가 '110-1111-1111'인 계좌(vt_bacnt)의 주인을 보여줘.
3. 전화번호가 '1000000001'인 통신 기기(vt_telno) 소유자 목록을 뽑아.
4. 사건번호가 'CASE-2023-001'인 사건(vt_case)에 연루된 사람들을 찾아줘.
5. IP 주소가 '203.108.1.223'인 IP를 통해 접속한 인물 리스트.

## [2단계] 방향성 및 단일 이력 추적 (Direction)
6. 피의자1 명의의 계좌에서 다른 사람 계좌로 출금(from_account)된 거래 이력 전체.
7. 특정 ATM 기기(ATM-001)에서 돈을 입금(to_account) 시킨 사람들의 이름.
8. '0100000001' 번호에서 전화를 발신(caller)하여 통화한 기록 전체.
9. 피해자1이 돈을 송금해서 최종적으로 돈을 받은 수신 계좌(to_account) 목록.
10. 불법 도박 집단이 사용한 의심 IP 세트와 연관된 접속 이벤트 내역.

## [3단계] 연산자(숫자, 날짜, 금액) 필터링 (Numeric/Date)
11. 이체 금액(amount)이 500만원(5000000) 이상인 거액 송금 거래 내역.
12. 통화 시간(duration)이 600초(10분)를 초과하는 통화 내역 중에 발신자 번호.
13. 이체 금액이 딱 10만원(100000)인 의심스러운 쪼개기 입금 거래들.
14. 등록일시가 '2023-05-01' 이후에 만들어진 모든 대포통장 리스트.
15. 거래 금액이 문자열 '50000'보다 작은(<=) 소액 이체내역을 찾아줘.

## [4단계] 네트워크 간접 경로 추적 (Path / Multi-hop)
16. 피해자1의 계좌에서 출발해 3단계 거쳐 피의자1에게 도달하는 자금 이동의 경로.
17. 피해자1과 피의자1 사이에 엮여 있는 공통된 관계망(전화, 이체 등)을 그려줘.
18. 서로 다른 3개의 금융 사기 사건에 동시에 공통으로 등장하는 핵심 피의자.
19. 범죄계좌 '110-1111-1111'에서 5단계를 거쳐 세탁된 자금의 최종 종착지 계좌들.
20. 수사 대상자 '피의자1'에서 시작해서 '피의자2'로 향하는 연결망 최단 경로를 추출해.

## [5단계] 일반 사용자 / 비격식 언어 테스트 (B2C & Entity)
21. 내 국민은행 통장('110-1111-1111')에서 무단으로 돈 빼간 사기꾼들 다 찾아줘.
22. SKT 폰 쓰는 애들 중에 금융 사기(CASE-99) 저지른 놈들만 솎아내봐.
23. 저 계좌(국민 010-1111-1111)가 토스뱅크에서 우리은행으로 돈 보낸 내역 싹 다 가져와.
24. 새벽에 IP 이상한데서 로그인한 놈들 누구야 찾아봐 줘.
25. 농협은행(NH)에 계좌 튼 사람 명단 싹 뽑아줘.

## [6단계] V3.3 신규 엣지/노드 검증 (사칭·진정서·출처)
26. 국민은행을 사칭한 전화번호 목록을 보여줘. (used_for → vt_impersonation → targets)
27. 진정서 PTN-001이 연결된 정식 수사 사건을 찾아줘. (filed_as)
28. 진정서 PTN-001과 유사한 다른 진정서들을 군집으로 보여줘. (clusters_with)
29. 계좌 '110-1111-1111'이 소속된 은행 조직을 알려줘. (belongs_to)
30. 서울 지역에서 발생한 이동 이벤트 목록. (occurred_at + vt_loc)
31. 피의자1과 동일인으로 확인된 인물들. (sameAs)
32. 더치트에서 수집된 데이터의 출처 확인. (sourced_from)

## [7단계] V3.4 신규 엣지 검증 (Ontology V3.4 Specific)
33. 이 사건에서 피의자가 직접 운영한 사이트나 텔레그램 채널 목록을 보여줘. (operates)
34. 총책이 모집한 조직원들과 각자의 역할을 알려줘. (recruits + recruit_type)
35. 이 사건에서 협박 피해자가 누구고 어떤 방법으로 협박받았어? (blackmails + method)
36. 피싱 사이트를 호스팅한 서버 IP와 그 국가를 추적해줘. (hosts)
37. 텔레그램 메시지나 피싱 사이트에 숨겨진 악성 파일 목록을 뽑아줘. (contains_file)
38. 피해자가 돈을 출금한 ATM의 위치와 CCTV 설치 여부를 알려줘. (located_at + vt_loc)
39. 조직 계층 전체를 보여줘 — 총책부터 말단까지 recruits 체인으로. (recruits*1..5)
40. 해외 서버에서 호스팅 중인 피싱 사이트와 연결된 악성 파일을 한꺼번에 보여줘. (hosts + contains_file 복합)
41. 이 사건의 피의자 중 대포통장을 실질 지배하는 사람과 그 계좌 목록. (controls)
42. 검찰청 사칭에 쓰인 전화번호, 사이트, 이메일을 사칭 이벤트 기준으로 묶어서 보여줘. (used_for → vt_impersonation)
