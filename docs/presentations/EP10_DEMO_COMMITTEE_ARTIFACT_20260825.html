핵심 발견 4가지

①해외 콜센터 근거지

IP 국가분포에서 태국·필리핀·일본·중국·싱가포르 495건, 통화 최다발신 번호는 필리핀(63) 국가번호로 159회. 서로 다른 두 데이터가 해외 소재 피의자 단서로 수렴.

②공유 IP = 콜센터 자동 분류

한 IP에 계정 27개가 접속(그 외 22·22개 IP도 존재). 온톨로지 v4.6의 ip_role 규칙이 "다수 실체가 공유하는 IP"를 콜센터로 자동 분류 — 사람이 세지 않아도 표시됨.

③070 인터넷전화 17개

사건에 직접 연결된 070 번호 17개. 콜센터의 통신수단으로, EP6(통신수단 수렴)·EP7(사용자 특정)의 실행 단서가 됨.

④대포통장 13개 = 한 조직

통장메모의 자금집계 태그 "피어스미디어"로 대포통장 13개·명의자 13명이 묶임. EP9-10 "인물 관점 → 조직 관점" 전환이 실데이터에서 성립함을 확인.
