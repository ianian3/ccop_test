### EP8 출입국 매핑 규칙 (2026-08-25 SoT 반영)

- **실측 결과**: 2차년도 전체에 출입국 **정형 데이터 없음** (전역 검색 0건 — 시나리오 질문과 스캔 수사보고 본문에만 등장). 규칙은 시나리오 요구 + 출입국 회신 실무 서식 기준으로 설계.
- **표현**: `vt_movement{mov_type:'immigration'}` 서브타입 — 신규 노드/엣지 0 (재학습 불필요 원칙 유지)

  - EP8 질의 예: `MATCH (p:vt_psn)-[:performed_by]-(m:vt_movement {mov_type:'immigration'}) WHERE m.timestamp >= ... RETURN p, m` — "해외 IP 활동기간과 출입국 기간 대조"
- **잔여**: 표준 DDL에 출입국 테이블 미보유 → 실데이터 확보(3차년도) 또는 DA 협의 시 `std_columns` 확정. SoT 회귀 테스트 53건 통과 확인.
