## 3. EP8의 수사적 의미
EP6~8은 카톡 3부작: EP6(예금주·의심)→EP7(IP역조회 실명)→EP8(3차 예금주·피해자/피의자). EP8은 **수사 4차 확장**으로 새 계정·IP를 추가하되, 콜센터 IP로 EP3/6/7과 계속 이어져 **조직 통신망의 지속성**을 보여준다. 통합 시 EP8 카톡 계정은 EP7 실명(`used_ip` 공유 IP 경유)으로 수렴.

## 4. 데이터 이슈·교훈
1. **파서 일반화**: EP6 카톡 파서에 `--ep-prefix`/`--src` 추가로 EP6·EP8 공용 — 형식 동일 EP는 파서 재사용.
2. **IPv6 보강**: 카톡 접속에 IPv6(`2001:2d8:...`) 68건 — IPv4 정규식만으론 누락, 콜론 2개 이상 hex 매칭 추가.
3. **대량 로그**: 메시지 36.3만건 → vt_ip 1.1만(개인 IP 다수). 콜센터 IP는 공유도(다계정)로 식별.
