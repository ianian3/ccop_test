## 2. 수사 분석 — 6하원칙 (실측)

- **누가 (Who)**: 070 명의자 17명(윤준호·노진성·김중섭·전혜진 등). 김은희 계좌 명의(자금 수취책).
- **언제 (When)**: 2017-02~03 (통화·거래 기간). EP1~3 신고·수사 기간과 연속.
- **어디서 (Where)**: 공유 접속 IP — 노진성·김석혁 등이 **122.54.197.66** 공유, 차승재 **122.54.197.65** (EP3와 동일 IP대역 = 같은 거점).
- **무엇을 (What)**: 통화망 825건 + 자금흐름 58건.
- **어떻게 (How)**: 070 인터넷전화 + 통화 + 계좌 세탁. EP4의 초점은 **범행 수법(팀미션 세탁)** — 계좌 입출금 패턴으로 자금 이동 확인.
- **왜 (Why)**: ★ **피어스미디어 집금** — 계좌 17개 belongs_to 피어스미디어, 자금흐름 총 **6.6억원**. 팀미션 사기의 자금이 여러 계좌 → 김은희 → 피어스미디어로 세탁·집금되는 구조가 EP4 "범행 구조 확인"의 핵심.

---

## 3. EP3 대비 — 같은 데이터, 다른 관점

EP3(단서 선별)와 EP4(범행 구조)는 **동일 회신 원본**을 공유하되 분석 목적이 다름:
- **EP3**: "단서를 어떻게 고르나" — 070·IP·계좌를 단서망으로 나열
- **EP4**: "범행이 어떻게 굴러가나" — 자금 세탁 구조(피어스미디어 집금)에 초점

그래프 규모는 거의 동일(070 17·자금 58·피어스 17계좌). 즉 EP4는 EP3 데이터의 **자금흐름 재해석** — 통합 시 EP3와 자연 병합됨.

---

## 4. 데이터 이슈·교훈

1. **EP 간 데이터 중복**: EP4의 012·013은 EP3 복사본. EP별 그래프는 독립 유지하되, 통합 시 공유 노드(계좌·전화·IP) MERGE로 자동 통합.
2. **NFD 파일명**: `find` 한글 매칭 실패 → python glob + NFC 정규화로 통화 폴더 탐색.
3. 미적재: 김은희 카톡(hwp)은 대화 로그라 별도 처리 필요(EP3 011 교훈 — 내용 제외·관계만).
