## 3. 수사 결론

그래프 확정 사실: **6일 / 중고나라 / 56건 / 5,210만원 / 대포통장 5개 수렴 / 070·다계정**. EP1 시나리오 답변("계좌·ID·070 반복 등장 + 더치트 연계 = 조직적 범죄")과 일치.

**미해결 — 주범 신원(Who의 최종 답)**: 명의자 5명은 인출책이며, 실사용자 특정은 EP3(070 통화·IP 역조회)·EP6~7(공유 IP→콜센터)로 이월. ep1_graph는 범행 윤곽·조직성을 확정했고, 주범 추적은 **EP1~3 통합 그래프**에서 이어짐.

## 4. 데이터 이슈·교훈

1. **숨김 시트 함정**: 004는 9시트 중 6개, 006은 12시트 중 11개가 **숨김**. 초기에 숨김 시트(접수-일람이·단서정리, 예금주 '이주영')를 정본으로 오인·오적재 → 롤백(120노드) 후 visible 시트로 재구성. **파서에 `sheet_state=='visible'` 필터 추가**로 재발 방지.
2. **비식별 불일치**: 같은 실계좌·실사건이 시트마다 다른 가명(이주영/이진아, 계좌 49502669901012/49537520206057)으로 존재. visible 시트를 정본 기준으로 채택.
3. **vt_id 분류**: 카톡 닉네임(괄호)과 계정ID를 `id_type`으로 구분 적재(식별력 차이).
4. **sameAs 후보**(엔티티 해소, candidate_only·verified=false): 마스킹 접두(traveller5↔traveller5\*\*\*\*)·플랫폼 교차 핸들(coma1576 kakao↔naver) — 자동 확정 금지, 수사관 검토 대기.

## 5. 재현 방법

```bash
# 그래프 생성
psql: CREATE GRAPH IF NOT EXISTS ep1_graph;
F='.../EP1. DS-01 (비식별화)/004_0000-03-29 접수내역★_비식별화.xlsx'
# 접수내역형 (01, 03)
python3 scripts/ingest_receipt_ledger.py --graph ep1_graph --xlsx "$F" \
  --sheet '01_신고사건 15건 정리' --src-id EP1-004-01 --case-prefix EP1-01
python3 scripts/ingest_receipt_ledger.py --graph ep1_graph --xlsx "$F" \
  --sheet '03_신고사건과 연결된 더치트 단서' --src-id EP1-004-03 --case-prefix EP1-03
# 더치트 검색확장형 (02)
python3 scripts/ingest_thecheat_search.py --graph ep1_graph --xlsx "$F" \
  --sheet '02_더치트 검색 방법' --src-id EP1-004-02
```
- 전부 멱등(MERGE) · 결정론 파서(LLM 무관, 환각 0) · 숨김 시트 기본 거부.
- 관련: EP2 = `ep2_graph`(017 더치트2차 158사건·계좌28), 통합 예정 = `ccop_ep_integrated`.
