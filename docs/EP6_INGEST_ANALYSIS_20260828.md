## 3. EP6의 수사적 의미
EP1~5가 "무엇을·누가(명의)·자금"이었다면, **EP6는 흩어진 통신수단(전화·카톡·구글·네이버)을 콜센터 IP로 묶어 "조직 거점"을 드러냄**. 명의(070·카톡·계좌)는 위장이고, 공유 IP가 실운영 주체를 가리킨다. EP7(핵심 IP 기반 사용자 특정)의 직접 전제.

## 4. 데이터 이슈·교훈
1. **카톡 로그 통일 형식**: EP3 011(대화내용형)과 달리 EP6은 시각+IP형(내용 없음) → 접속IP 수렴 분석에 최적. 전용 파서로 27개 일괄.
2. **국가코드 식별**: 카카오ID 앞자리로 해외 계정 판별(852/63) — 해외 위장 탐지 핵심.
3. **네이버 역조회 = 실명 특정**: 전화→네이버ID→이름, 통신사 전화조회로 명의 확보(070·카톡 명의 뒤 실사용자 재료).
