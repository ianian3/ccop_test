## 0. 설계 의도 재확인

> **Modeler 는 사용자가 V4.0 온톨로지에 얽매이지 않고 자체 그래프 스키마를 자유롭게 설계·시각화하는 도구다.**

- `KICS_NODES` / `KICS_EDGES` 하드코딩은 **빠른 시작용 라이브러리** (입력 가이드일 뿐)
- V4.0 SSOT API 호출이 없는 것은 **버그가 아니라 의도된 자유도**
- V3.7 신규 요소(`pt_cluster` 등) 미반영도 **사용자가 필요 시 직접 정의**할 수 있는 영역

## 3. V4.0 통합 — 선택적 가능 옵션

> 강제 적용이 아닌, 사용자가 원할 때 **선택적으로** 활용 가능한 기능 제안.

### 3.1 ⚪ 옵션 A — V4.0 프리셋 import 버튼
"V4.0 표준 라이브러리에서 가져오기" 토글 버튼 추가. 클릭 시:
```
1. /api/v1/visual-style 호출 → 25 노드 프리셋 팔레트로 추가
2. /api/v1/edge-style 호출 → 55 엣지 프리셋 팔레트로 추가
3. 기존 KICS_NODES / KICS_EDGES 는 그대로 유지 (사용자 선택권 보존)
```
- 효과: 사용자가 V4.0 표준 시작점이 필요할 때만 가져옴
- 비파괴: 자유 정의 기능은 그대로 유지

### 3.2 ⚪ 옵션 B — V4.0 메타 옵트인 체크박스
노드/엣지 생성 폼에 "V4.0 메타 표준 부착" 체크박스 (기본 꺼짐).
- 켜면: `id_format`, `source_domain`, `reliability_tier` 입력 칸 노출 + `make_node_props_v40` 호출
- 끄면: 현재 동작 그대로 — 사용자 정의 자유

### 3.3 ⚪ 옵션 C — modeler ↔ index.html 의 V4.0 그래프 전환 동선
modeler 에서 만든 그래프를 V4.0 메타 표준화 후 `index.html` 에 보내는 변환 마법사. **별도 도구**로 제공해 본연 modeler 기능 보존.

## 4. 권장 (사용자 의도 우선)

기본은 **현 상태 유지**. V4.0 통합이 필요한 사용자 요구가 명시적으로 발생하면 §3 옵션 A/B/C 중 선택적으로 추가.

- ❌ **하지 말 것**: `KICS_NODES` / `KICS_EDGES` 를 V4.0 SSOT 로 강제 덮어쓰기
- ❌ **하지 말 것**: modeler 의 자체 Cypher 파이프라인을 `index.html` 의 V4.0 동적 오버레이 패턴과 통일
- ❌ **하지 말 것**: V4.0 메타 6컬럼 자동 부착을 모든 modeler 노드에 강제

- ✅ **해도 됨**: V4.0 프리셋을 옵션 메뉴로 노출 (옵션 A)
- ✅ **해도 됨**: V4.0 메타 부착을 옵트인 체크박스로 제공 (옵션 B)
- ✅ **해도 됨**: 변환 마법사 별도 도구 제공 (옵션 C)
