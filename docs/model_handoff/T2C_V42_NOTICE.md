# NOTICE — 라이선스 및 데이터 취급 고지

## 라이선스

| 구성물 | 라이선스 | 비고 |
|---|---|---|
| 베이스 모델 (Qwen2.5-7B-Instruct) | Apache-2.0 | Alibaba Cloud / Qwen |
| 파인튜닝 가중치 (LoRA 병합분) | CCOP 프로젝트 산출물 | 내부 자산 — 배포 범위는 프로젝트 정책에 따름 |
| 학습 데이터셋 (`t2c_v37`) | 내부 생성 | **⚠️ 아래 민감도 고지 참조** |
| 벤치마크/코드 | CCOP 프로젝트 | — |

## ⚠️ 데이터 민감도

- `dataset/t2c_v37_*_msg.json` 은 **수사 도메인 온톨로지 기반 합성 데이터**다. 실제 개인정보(실명/실계좌/실전화)는 포함하지 않도록 생성됐으나, **스키마·질의 패턴 자체가 수사 방법론을 담고** 있다.
- **조직 외부(사외) 전달 전 반드시 보안/법무 검토**를 거칠 것. 실데이터가 아니어도 도메인 노하우가 노출될 수 있다.
- 병합 가중치는 이 데이터로 학습됐으므로 동일 기준으로 취급.

## 사용 제한

- 이 모델은 **수사 지원 도구**용이다. 생성된 Cypher/결과는 참고 정보이며, 수사 판단·법적 효력을 갖지 않는다.
- 조회 전용으로 학습·설계됨. 쓰기(CREATE/DELETE 등) 용도로 사용 금지.

## 재배포

- 베이스(Qwen2.5) 부분은 Apache-2.0 조건(저작권 고지 유지 등)을 따른다.
- 파인튜닝 산출물·데이터의 재배포는 CCOP 프로젝트 승인 필요.
