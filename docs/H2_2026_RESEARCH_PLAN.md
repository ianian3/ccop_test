# CCOP v1.0 — 2026 하반기 고도화 연구계획

**작성일**: 2026-06-29
**대상 기간**: 2026년 7월 ~ 12월 (H2)
**주제**: 범죄수사 그래프 분석 플랫폼 **고도화** (성능·정확도·운영성·확장성)

---

## 1. 배경 — 상반기 성과와 고도화 과제

### 1.1 상반기 달성 (현 수준)

| 영역 | 달성 |
|------|------|
| **온톨로지** | KICS POLE 6계층 **V4.0 통합본** 확정 — 노드 25 / 엣지 53, 도메인 사용 매트릭스·식별자 표준·추론 규칙 메타 격상 |
| **Text2Cypher** | 운영 표준 **v42 + Router 86.6%(201/232)** 달성 (운영 임계 85% 충족) |
| **통합 DBMS** | AgensGraph(PG+AGE) 단일 엔진, Cypher→AGE SQL 래핑, tccopdb 9개 그래프 운영 |
| **데이터 표준화** | StandardCodeMapper(금결원·통신사·해시) 적재 시 자동 정규화 |
| **운영 배포** | skai2_vm e2e 동작, 외부기관 조회 API, 대규모 OSINT 적재 파이프라인 **설계** 완료 |

### 1.2 고도화가 필요한 지점 (하반기 출발점)

- **T2C 모델 약점 잔존** — Router는 잡담/가드 분기만 해결, **21개 Cypher 카테고리는 v42와 동일**. 다음 카테고리가 운영 임계 미달:
  - `meta_condition` 60.0% · `1hop_event` 60.0% · `chain` 66.7% · `1hop_object` 70.0% · `1hop_person` 80.0%
  - **v3.6 신규 엣지 62.5%** (목표 65% 미달, v41이 66.1%로 최고였으나 트레이드오프)
- **v43 catastrophic forgetting** — 특정 카테고리 집중 보강이 prior 전체 망각 유발(폐기). → 안전한 **continue-learning 전략 필요**.
- **라우터 sLLM 폴백 품질** — Router·reflection은 OpenAI 키 있을 때만 `gpt-4o-mini`, 망분리 시 sLLM 폴백 → 의도 분류 정확도 저하.
- **온톨로지 SoT 이원화** — `middleware/services` vs `services` 통합 미완.
- **대규모 OSINT 적재 production화 미완** — `osint_ontology` 6.89M 노드/10.94M 엣지 규모, 설계만 완료.
- **망분리·운영 인프라 하드닝 미완** — 폐쇄망 패키징, docker IP 고정, 정식 인증서, 자동 CD, 시크릿 정리.

## 2. 하반기 고도화 목표

### 2.1 정량 목표 (KPI)

| 지표 | 현재 | 하반기 목표 |
|------|------|-------------|
| T2C 실행 성공률 (232문항) | 86.6% | **≥ 92%** |
| v3.6 신규 엣지 정확도 | 62.5% | **≥ 75%** |
| 약점 카테고리 (meta_condition·1hop_event·chain) | 60~67% | **≥ 80%** |
| 망분리 sLLM 라우팅 정확도 | (미측정) | **≥ 90%** (규칙+보강) |
| 대규모 OSINT 적재 처리량 | (배치) | **≥ 100만 건/시간** 상시 적재 |
| 운영 가용성 (외부 시연 포함) | 수동 의존 | **자동 복구·자동 CD 체계화** |

### 2.2 정성 목표

1. **모델 단독 실력 향상** — 라우터 의존이 아닌 Cypher 생성 본연의 정확도 제고(v44).
2. **망분리(폐쇄망) production 배포** — 외부 의존 0으로 동작하는 패키지·운영 체계 확립.
3. **온톨로지 자동추론 엔진 고도화** — 추론 규칙 확장 + 단일 SoT 통합.
4. **대규모 데이터 상시 통합** — OSINT 수백만 건의 안정적 정제·적재·조회.

## 3. 고도화 5대 축

### 축 1. Text2Cypher 모델 고도화 — `v44 continue-learning`

**목표**: 실행 성공률 92%+, 약점 카테고리 80%+, catastrophic forgetting 회피.

| 과제 | 접근 |
|------|------|
| 1-1. 약점 카테고리 보강 | `meta_condition`·`1hop_event`·`chain`·신규엣지 타깃 SFT 데이터 증강 (카테고리 균형 유지) |
| 1-2. 안전 학습 전략 | **v42 어댑터 위 continue-learning** — lr↓·epochs↓, prior 보존(v43 망각 교훈 반영) |
| 1-3. 회귀 방지 평가 | 232문항 + 카테고리별 회귀 게이트 — **특정 카테고리 ≥ -5p 이내** 자동 차단 |
| 1-4. 라우터 의존 분리 측정 | 모델 단독 vs +Router 분리 리포트로 "실력 향상분" 명시 |

**산출물**: v44 머지 모델, 카테고리별 평가 리포트, SFT 증강 데이터셋.

---

### 축 2. 온톨로지 고도화

**목표**: 자동추론 규칙 확장 + 단일 SoT 통합으로 유지보수성·표현력 제고.

| 과제 | 접근 |
|------|------|
| 2-1. SoT 단일화 | `app/middleware/services/ontology_service.py` → `app/services/` 통합, alias 제거 |
| 2-2. 추론 규칙 확장 | relay_station·site_cluster·pt_cluster 외 신규 추론(군집/허브/공범 패턴) 후보 발굴·검증 |
| 2-3. 추론 엔진 자동화 | 적재 후 추론 규칙 일괄 적용 파이프라인(배치/증분) 정비 |
| 2-4. 온톨로지 검증 | 노드/엣지 정합성·식별자 형식·도메인 매트릭스 자동 검사 테스트 |

**산출물**: 통합 ontology_service, 추론 규칙 카탈로그 v4.x, 검증 테스트.

---

### 축 3. 통합 DBMS · 대규모 데이터 적재 고도화

**목표**: 수백만 건 OSINT 상시 적재 + 그래프 조회 성능 확보.

| 과제 | 접근 |
|------|------|
| 3-1. 적재 파이프라인 production화 | OSINT→전처리→CCOP 3단계 파이프라인 설계를 운영 코드로 구현·자동화 |
| 3-2. 대용량 성능 | GIN 인덱스·청크 적재·배치 튜닝, `osint_ontology`(6.89M/10.94M) 기준 벤치마크 |
| 3-3. 조회 성능 | 자주 쓰는 패턴(1~2홉, 허브) 쿼리 프로파일링·인덱스/쿼리 최적화 |
| 3-4. 데이터 품질 | 표준화 룰셋 커버리지 확대(은행/통신사/해시 외 신규 코드계), 중복·결측 처리 |

**산출물**: 상시 적재 파이프라인, 성능 벤치마크 리포트, 표준화 룰셋 v2.

---

### 축 4. 분석·추론 기능 고도화 (Agentic)

**목표**: 단순 조회를 넘어 다단계 수사 추론·시각화 강화.

| 과제 | 접근 |
|------|------|
| 4-1. Agentic 질의 강화 | LangGraph 기반 multi-hop 추론·경로 탐색 정확도/안정성 개선 |
| 4-2. 네트워크 분석 | 1-mode 투영·2-mode 통계 등 공범/자금흐름 네트워크 분석 기능 고도화 |
| 4-3. 시각화·타임라인 | 노드 상세·타임라인·경로 하이라이트 등 수사 친화 시각화(상반기 미완분 반영) |
| 4-4. 보고서화 | 분석 결과 → 수사보고서/내보내기(i2 등) 자동화 검토 |

**산출물**: 개선된 agentic 엔드포인트, 네트워크 분석 기능, 시각화 개선.

---

### 축 5. 운영 · 망분리(폐쇄망) 인프라 고도화

**목표**: 외부 의존 0의 폐쇄망 production 배포 + 운영 자동화·보안 하드닝.

| 과제 | 접근 |
|------|------|
| 5-1. 폐쇄망 패키징 | 사전빌드 이미지·모델·DB 덤프 반입 번들 체계, 오프라인 설치 절차 표준화 |
| 5-2. 망분리 라우터 | OpenAI 미사용 시 **규칙 기반 라우터 + 의도분류 보강 학습**으로 품질 확보(축1 연계) |
| 5-3. 안정성 | docker IP 고정(IPAM), 정식 인증서, 자동 CD, 자동 백업/복구 검증 |
| 5-4. 보안 | 커밋된 시크릿 정리, 접근통제(ACG/Basic Auth), 감사 로깅 |

**산출물**: 폐쇄망 배포 가이드(완성)·번들 도구, 규칙 라우터, 인프라 하드닝 적용.
