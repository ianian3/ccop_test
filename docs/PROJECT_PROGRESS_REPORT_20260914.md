# 사이버범죄 수사 그래프 분석 플랫폼(CCOP) 과제 진행 보고

작성일: 2026. 9. 14. / 작성: 스카이월드와이드

## 1. 개요

본 과제는 사이버범죄 수사 과정에서 확보되는 이기종 자료(금융·통신·접속기록 등)를 표준 온톨로지에
따라 그래프 데이터베이스로 통합하고, 수사관이 자연어 질의만으로 관계 분석을 수행할 수 있는
플랫폼을 구축하는 것을 목표로 한다. 당 기간에는 온톨로지 표준의 고도화(V4.8), 2차년도 시나리오
데이터셋(EP1~EP10)의 전량 적재와 통합, 자연어-Cypher 변환 모델의 성능 개선 및 신뢰성 확보,
전처리 기관 연계 규격의 정비를 중심으로 연구를 수행하였다.

## 2. 수행 내용

### 2.1 수사 온톨로지 표준 V4.8 확정

온톨로지 표준을 V4.7(2026. 8. 13. 확정 — 법인 대표 관계, 직업 속성, 표준 컬럼 매핑 반영)에서
V4.8로 고도화하였다. V4.8에서는 위치 개념(vt_loc)을 확장하여 통화 발신 기지국, ATM 설치 지점,
금융기관 영업점의 3계열 위치 체계를 확립하였으며, 현행 표준은 노드 25종, 엣지 72종(활성 70종,
폐기 예정 2종)으로 구성된다.

아울러 적재 결과가 표준을 준수하는지 자동 검사하는 정합 감사 도구를 개발하였다. 감사 항목은
표준 외 라벨·엣지 사용 여부, 폐기 예정 엣지 사용 여부, 관계의 정의역·치역 위반, 식별 속성
충전율, 원본 출처 식별자 보유율의 여섯 가지이며, 개별 사건 그래프 전체와 통합 그래프에 대하여
위반 0건을 유지하고 있다. 감사 과정에서 표준이 선언한 식별 속성과 실제 적재 속성이 불일치하는
사례 4건(인물·ATM·기관·출처의 식별자)을 확인하였는데, 이는 비식별화 데이터에 인물 관리번호가
부재하여 이름을 식별자로 운용한 데 따른 것으로, 감사 결과에 경고로 노출하여 표준 개정 또는 적재
보완 여부를 검토 중이다.

### 2.2 2차년도 데이터셋 적재 및 통합

2차년도 시나리오 데이터셋 EP1~EP10 전량의 그래프 적재를 완료하였다(2026. 9. 2.). EP1~EP8은
결정론적 파서로 처리하여 대규모 언어모델 기반 추출에서 발생할 수 있는 환각(존재하지 않는 관계의
생성)을 원천 차단하였고, 정형 자료가 없는 EP9·EP10은 수사기록 대조 검증을 거친 수동 확정
시드로 구축하였다. 이후 잔여 백로그를 해소하여, 암호화 문서로 미적재 상태였던 기업은행 건별
거래내역 1,593건(이체 관계 263쌍, 거래 IP 103건, 거래점 27개소 파생)과 발신 기지국 85건, ATM
위치 46건을 추가 적재하였다. 주소가 확인되지 않는 ATM 17건에 대해서는 지점명으로부터 소재지를
추정하지 않는 원칙(근거 없는 정보의 그래프 유입 차단)에 따라 위치 노드를 생성하지 않았다.

개별 사건 그래프는 물리 식별자(계좌번호·전화번호·IP·메신저 계정) 기준으로 병합하여 통합
그래프를 구축하였으며, 현재 규모는 24,720 노드, 26,089 엣지이다. 전체 노드의 100%가 원본 문서
식별자(source_id)를 보유하여 분석 결과의 각 요소에서 원본 자료로의 역추적이 가능하다. 병합 시
각 노드에 출처 사건 목록과 출처 수를 부여함으로써 다수 사건에 걸쳐 등장하는 단서를 즉시 조회할
수 있도록 하였고, 실제로 동일 IP 1건이 5개 사건에서 공유된 사실을 확인하여 조직 공용 기반시설
탐지 가능성을 실증하였다.

또한 압수자료의 IP 접속기록과 명의 정보를 시간구간 교차 방식으로 결합하여 메신저 위장계정의
실사용자를 결정론적으로 특정하는 절차를 확립하였다. 수사기록 정답과 대조한 결과 대상 사건에서
각각 62명 중 62명(정답 64명 대비), 40명 중 40명이 일치하였다.

### 2.3 자연어 질의(Text2Cypher) 모델 고도화

자연어-Cypher 변환 모델의 차기 버전(v48, Qwen2.5-Coder-7B 기반 LoRA 미세조정)을 학습하고 3중
게이트 평가를 거쳐 채택하였다(2026. 9. 3.). 게이트 결과는 신규 70문항 중 68문항 통과(97.1%),
기존 232문항 회귀 시험에서 유의미한 성능 저하 없음, 데이터 변조 시도 질의 차단률 100%이다.
학습 시와 추론 시의 시스템 프롬프트 정합이 성능의 일차 결정 요인임을 실증하였으며(프롬프트
정합화만으로 추가 학습 없이 정확도 2.8%p 향상), 이를 그래프별 프롬프트 분기 구조로 플랫폼에
반영하였다.

모델 출력에 대한 실행 후 보정 계층을 구축하였다. 질의 결과가 0건인 경우 대상 노드의 실제 이웃
분포를 조회하여 중간 노드를 경유하는 2단계 경로로 질의를 재합성하고, 질문과 데이터베이스 어느
쪽에도 근거가 없는 값(환각 리터럴)을 검출하며, 위치 명칭은 부분일치 조회로 전환한다. 아울러
평가 절차 자체의 신뢰성을 보증하기 위하여 시스템이 보강한 결과 행과 모델이 실제 산출한 결과
행을 분리 계측하고 평가 전후 데이터 무결성을 검사하는 장치를 도입하였다. 이 장치를 통해 표면
성적 88% 가운데 7건의 거짓 통과를 적발하였고(실질 81%), 보정 로직 개선을 거쳐 신규 100문항
홀드아웃 기준 93%를 달성하였다.

### 2.4 플랫폼 운영 및 보안 체계

시연용 환경과 개발용 환경을 분리 운영한다. 외부 시연용 환경은 접근 가능 그래프를 테스트 전용
그래프로 한정하고, 개발용 환경은 로컬에서 운영 데이터를 대상으로 한다. 데이터베이스 접근 권한은
슈퍼유저에서 읽기 전용 계정으로 하향하였으며, 쓰기 가능 그래프를 화이트리스트(테스트 그래프
1종)로 제한하여 운영 데이터 변조 가능성을 차단하였다.

### 2.5 전처리 기관 연계 규격 및 도구

전처리 기관이 표준 규격에 따라 데이터를 제출할 수 있도록 CSV 적재 규격 V4.8 개정판을
작성하였다. 기존 9종 파일의 컬럼을 전면 유지하는 하위호환을 원칙으로 하고, 원본 대조를 위한
출처 식별자(source_id), 계좌 오병합 방지를 위한 은행코드(bank_cd), 통화·문자·메신저 구분을
위한 연락수단(channel) 등의 추가 컬럼과 선택 파일 4종(IP 접속, 계정 소유, 계정 간 메시지,
위치)을 정의하였다. 제출 기관의 작성 부담을 줄이기 위해 빈 템플릿 13종(필수 9종, 선택 4종)과
동일 구성의 작성 예제 13종을 제작하였고, 제출 전 자체 점검용 검증 도구(데이터베이스 연결 없이
파일만으로 규격·참조 정합을 검사)와 규격의 동작을 코드로 확인할 수 있는 적재 참조 구현을 함께
제공하도록 준비하였다.

전체 흐름(규격 검증 → 그래프 적재 → 온톨로지 정합 감사)을 독립 환경에서 검증 완료하였으며,
전처리 기관 제출 데이터가 기존 사건 데이터와 물리 식별자 기준으로 자동 교차 연결됨을
실증하였다. 아울러 통합 플랫폼 구축 기관에 온톨로지 V4.8 표준을 전달하기 위한 패키지(기계
가독형 정의 명세, 실측 스키마 카탈로그, 관계형 표준 DDL 51테이블, 정합 감사 도구)를
완성하였다.

## 3. 주요 성과 요약

당 기간의 정량 성과는 다음과 같다. 통합 그래프 24,720 노드·26,089 엣지(2차년도 시나리오 전량,
원본 출처 식별자 보유율 100%), 온톨로지 정합 감사 위반 0건, 자연어 질의 모델 게이트 평가
97.1%(70문항)·홀드아웃 93%(100문항)·데이터 변조 차단 100%, 위장계정 실사용자 특정 정확도
62/64·40/40, 전처리 기관 제공 산출물 4종(규격서, 템플릿·예제 각 13종, 검증 도구, 적재 참조
구현) 완성. 정성 성과로는 결정론 파서에 의한 무환각 적재 체계, 추정 금지 원칙에 따른 증거성
보전, 평가 무결성 장치에 의한 성능 수치의 신뢰성 확보, 사건 간 교차 단서(공용 IP 등) 자동
탐지의 실증을 들 수 있다.

## 4. 문제점 및 조치 사항

운영 환경의 그래프 데이터베이스(개발 빌드 버전)에서 특정 형태의 질의(경로 순회와 비앵커 노드
속성 조건의 결합)가 백엔드 프로세스의 비정상 종료를 유발하는 결함을 발견하였다. 해당 형태를
실행 전에 정적으로 탐지하여 차단하고 의미가 동일한 안전 형태로 자동 재작성하는 방어 계층을
적용하여 운영 영향을 차단하였으며, 근본 조치로서 안정 버전으로의 교체를 관리 주체에 요청할
예정이다.

평가 과정에서는 결과 보강 로직이 실패 사례를 가려 성능이 과대 표시되는 문제와, 벤치마크 문항에
포함된 쓰기 질의가 평가 대상 데이터를 변조하는 문제를 확인하였다. 각각 보강 행 분리 계측과 평가
전후 무결성 검사를 도입하여 재발을 차단하였고, 이후의 모든 성능 수치는 해당 장치 적용 후
기준으로 보고한다.

## 5. 향후 계획

전처리 기관에 규격 회신을 발송하고 문의 항목(파일 1종의 정체)을 확인하여 필요 시 규격 항목을
추가한다. 제출 데이터 수신 시 검증-적재-감사 파이프라인을 실전 적용하고, 자연어 질의 모델의
차기 버전(v49)을 위한 학습 데이터 보강(관계 방향·어휘 공백 해소)을 진행한다. 아울러 수행
과정에서 발굴된 특허 후보(압수자료 교차 기반 위장계정 실사용자 특정 방법, 출처 다중도 기반 단서
순위화 등)에 대하여 과제 협약상 권리 귀속 절차를 확인한 후 출원을 검토할 예정이다.
