## 1. 🔴 핵심 결함: 엣지 생성 UX

### 현황
- 엣지 추가 = `[관계(엣지) 정의]` 버튼 클릭 → 모달 → src/tgt/type 입력 → 추가
- **캔버스 직접 드래그-연결 불가** (`cytoscape-edgehandles` 플러그인 미로드, [modeler.html:7](../app/templates/modeler.html#L7) script 태그 확인)
- 노드 2개를 시각적으로 보면서 "끌어서 연결" 하는 직관 차단

### 영향
- 그래프 모델러에서 가장 기본이 되는 인터랙션이 막혀 있어 **초보자 진입장벽 ↑**, **숙련자 효율 ↓**
- 자유 설계 도구의 핵심 가치(직관적 시각화)를 해침

### 권장
- `cytoscape-edgehandles` 플러그인 추가 (CDN 1줄)
- 노드 hover 시 작은 ⊕ 핸들 표시, 끌어서 다른 노드에 연결
- 연결 후 자동으로 엣지 타입 모달 띄움 (기존 모달 재사용 가능)

## 2. 🔴 핵심 결함: 자동저장 단일 슬롯

### 현황 ([modeler.html:1401](../app/templates/modeler.html#L1401))
```js
localStorage.setItem('ccop_modeler_autosave', JSON.stringify(saveData));
```
- 그래프 이름과 무관하게 **단일 키 `ccop_modeler_autosave`** 에 덮어쓰기
- 사용자가 그래프 A 작업 → 그래프 B 작업 시작 → 그래프 A 자동저장 **소실**
- 백업 수단은 사용자가 수동으로 `[JSON으로 저장]` 다운로드 한 경우뿐

### 영향
- 다중 프로젝트 작업 시 데이터 유실 위험 → **자유 설계 도구로서 치명적**

### 권장
- 키 네이밍 변경: `ccop_modeler_save:${graphName}` 형식
- 또는 `ccop_modeler_workspace` 객체 안에 `{ [graphName]: data }` 구조
- 자동 복원 시 그래프 이름으로 매칭, 없으면 "최근 작업" 메뉴 제공

## 3. 🟡 노드 추가 — 위치 예측 불가

### 현황 ([modeler.html:862](../app/templates/modeler.html#L862))
```js
const pos = { x: 120 + (cy.nodes().length % 5) * 130,
              y: 100 + Math.floor(cy.nodes().length / 5) * 120 };
```
- 팔레트 클릭 시 5×N 그리드로 자동 배치
- 사용자가 어디에 떨어질지 예측 불가, **이미 노드가 있는 자리에 겹침**

### 권장
- 옵션 A: 드래그-드롭 (HTML5 DnD API) — 팔레트에서 캔버스로 끌어다 놓기
- 옵션 B: 클릭 후 캔버스의 **다음 클릭 지점**에 배치 (커서 변경)
- 옵션 C: 마지막 선택된 노드 근처에 배치

## 4. 🟡 단축키 부족

| 단축키 | 현재 | 권장 |
|--------|------|------|
| Ctrl+Z / Ctrl+Y | ✅ Undo/Redo | (유지) |
| **Delete / Backspace** | ❌ | **선택 요소 삭제** (현재는 우측 패널 버튼만) |
| **Esc** | ❌ | **선택 해제 + 모달 닫기** |
| Ctrl+S | ❌ | JSON 저장 단축키 |
| Ctrl+E | ❌ | 엣지 정의 모달 열기 |
| `+` / `-` | ❌ | 줌 인/아웃 |

## 5. 🟡 캔버스 모드 토글 (선택/이동)

### 현황 ([modeler.html:205-206](../app/templates/modeler.html#L205))
- 명시적으로 "선택 모드 / 이동 모드" 버튼 클릭 필요

### 표준 패턴 (Figma/Miro/draw.io 등)
- 빈 영역 클릭 = pan, 요소 클릭 = select 자동 분기
- 또는 spacebar 누른 상태에서만 pan

### 권장
- Cytoscape 기본 `boxSelectionEnabled: true` + 빈 영역 드래그 = pan 활성화
- 모드 토글 버튼은 옵션으로 유지하되 기본은 자동

---

## 6. 🟡 검증/오류 메시지

### 현황 ([modeler.html:1239-1252](../app/templates/modeler.html#L1239))
- graphName 빈 입력 → 토스트 메시지만
- 백엔드 오류는 그대로 `data.message` 노출
- **노드 라벨 중복, 엣지 동일 src/tgt/type 중복, 영문 외 문자** 등 인라인 검증 없음

### 권장
- 그래프 이름 입력창 옆 인라인 검증 (영문/숫자/_만 허용 정규식)
- 노드 추가 시 동일 라벨 중복 경고 (사용자가 의도적으로 같은 라벨 여러개 만들 수 있게는 허용)
- 엣지 모달에서 src/tgt 동일 + 동일 type 이면 경고 (self-loop는 명시적 사용자 의도)

## 7. 🟢 잘된 점 (보존 권장)

1. **3-Panel 구조**: 팔레트(왼쪽) / 캔버스(중앙) / 속성(오른쪽) — 표준 패턴 충실
2. **온보딩 모달 + 템플릿 2종**: 보이스피싱/자금추적 빠른 시작 — 신규 사용자 진입 친절
3. **Cypher 출력 모달**: 생성 → 실행 단계 분리로 사용자가 검토 후 실행 가능
4. **3단계 워크플로** (Cypher 생성 → 그래프 생성 → 데이터 적재) — 의도 명확
5. **JSON Import/Export**: 외부 백업 가능 — 단일 슬롯 자동저장 결함의 안전망
6. **RDB 가져오기 위저드 2단계**: 테이블 선택 → 컬럼 매핑 — 명확한 흐름
7. **1-mode / 2-mode 네트워크 토글**: 고급 사용자용 — 좋은 부가 기능 (단, 설명 보강 필요)

## 8. 우선순위별 권장 패치

### 🔴 P0 — 데이터 유실 차단 (~30분)
- `localStorage` 키를 `ccop_modeler_save:<graphName>` 로 분리
- 그래프 이름 변경 시 마이그레이션
- "최근 작업 N개" 메뉴 추가

### 🔴 P1 — 엣지 드래그-연결 (~1h)
- `cytoscape-edgehandles@4.x` CDN 추가
- 노드 hover 시 ⊕ 핸들 표시
- 드롭 후 기존 엣지 모달 자동 호출 (src/tgt 사전 입력)

### 🟡 P2 — 단축키 보강 (~20분)
- `Delete` / `Backspace` → 선택 요소 삭제
- `Esc` → 선택 해제 + 모달 닫기
- `Ctrl+S` → JSON 저장

### 🟡 P3 — 캔버스 인터랙션 현대화 (~40분)
- 빈 영역 드래그 = pan 자동
- 모드 토글은 옵션으로 유지
- 줌 +/- 버튼 추가

### 🟢 P4 — 검증/메시지 강화 (~30분)
- 그래프 이름 인라인 정규식 검증
- 중복 라벨/엣지 경고 (블로킹 아닌 안내)

### 🟢 P5 — 노드 배치 예측 가능화 (~20분)
- 마지막 선택 근처 또는 마우스 위치에 배치

**총 권장 작업량**: ~3h 30분 (전체) / P0+P1+P2 만 ~2h

## 9. 결론

Modeler 의 **본연 가치(자유 설계)** 는 명확하나, **엣지 드래그-연결 부재**와 **자동저장 단일 슬롯**이 사용자 경험을 크게 저해. 이 2건만 해결해도 자유 설계 도구로서의 체감 품질이 큰 폭으로 개선될 것.

V4.0 SSOT 통합과는 별개 트랙으로 추진 권장 — modeler 자체의 UX 완성도가 우선.
