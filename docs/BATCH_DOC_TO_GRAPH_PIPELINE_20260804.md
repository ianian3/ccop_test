# 1차년도 데이터 폴더 → 수사 그래프 배치 파이프라인

> **작성일**: 2026-08-04
> **질문**: "1차년도 연구과제 데이터 폴더 전체를 입력해 LLM 추출·온톨로지 검증·수사 그래프 파이프라인을 구축한다면?"
> **답**: 단일 LLM 파이프라인이 아니라 **하이브리드 3-트랙**이어야 한다. 데이터의 절반이 정형(표)이고, LLM 추출은 정형 데이터에 부적합·낭비이기 때문. 비정형 트랙은 **구축·실증 완료**.

## 2. 하이브리드 3-트랙 아키텍처

```
1차년도 폴더 (376 파일)
│
├─ [트랙 A] 정형 (xlsx/xls/csv 110)
│     → etl_service 컬럼→온톨로지 매핑 → 직접 MERGE
│     ※ 계좌거래내역·IP리스트 등은 표 구조가 이미 정답 — LLM은 오히려 오류·낭비
│
├─ [트랙 B] 비정형 (pdf/hwp/docx/txt/hwpx 120)   ★구축·실증 완료
│     parse_document(어댑터) → chunk → LLM 추출(온톨로지 제약)
│     → validate(할루시네이션 폐기) → 크로스-문서 엔티티 해소 → MERGE
│
├─ [트랙 C] 정답 (anb 17)
│     i2 파싱 → gold 그래프 → 트랙 A·B 추출결과와 대조 정확도평가
│     ※ 05폴더 13개는 우리가 추출한 동심우 시나리오의 i2 정답지
│
└─ [트랙 D] 이미지 (png/jpg 57) → OCR → 트랙 B (향후)
│
└─(공통) 크로스-문서 엔티티 해소 · provenance(source_id·tier·confidence) · MERGE 적재
```

**설계 핵심**: 형식별로 최적 경로가 다르다. 정형은 규칙(ETL)이 LLM보다 정확·저렴하고, 비정형만 LLM의 값어치가 있다. i2는 이 둘을 **모두 수동**으로 처리 — CCOP는 정형=자동ETL, 비정형=자동LLM.

## 3. 트랙 B 구축·실증 (완료)

### 구현
| 파일 | 역할 |
|---|---|
| `app/services/document_extraction_service.py` | 파서 어댑터(`parse_document`: hwpx/pdf/docx/hwp/txt) + LLM 추출(온톨로지 제약, 잘린 JSON 복구) + 검증 |
| `scripts/batch_doc_to_graph.py` | 폴더 워크 → 배치 추출 → **크로스-문서 엔티티 해소** → provenance 집계 |

- **파서**: 지연 import로 base 의존성 0 유지(pypdf/olefile 선택). hwpx·pdf·docx·txt 즉시 / hwp는 olefile PrvText(설치 시).
- **크로스-문서 해소**: 전화/계좌 정규화 키로 문서 간 동일 실체 통합. 식별자 없는 폴백은 **문서 스코프 격리**(오통합 방지).
- **provenance**: 엔티티마다 `sources`(등장 문서 목록) + `reliability_tier`(영장·판결=1 / 수사보고=2 / 기타=3).

### 실증 결과 — 03 중고나라 법률문서 6건
```
처리: 6/6 (pdf)  |  고유 엔티티 98  |  관계 45  |  노드 11종 / 엣지 9종
스키마밖 폐기(할루시네이션 필터): 30건 (accessed_ip·transfer_to 등 온톨로지 밖)

🔗 크로스-문서 엔티티 (i2 수동연결을 자동): 4건
   vt_psn  윤연희          ← 4개 문서 (체포영장·공소장·판결문·조회서)
   vt_bacnt 3521204075933 ← 2개 문서
   vt_psn  임건수          ← 2개 문서
   vt_ip   203.0.113.5    ← 2개 문서
```

**입증된 결정적 차별**: 체포영장·공소장·판결문에 흩어진 피의자 `윤연희`와 계좌를 **자동으로 하나의 노드로 통합**. i2 Analyst's Notebook에선 분석가가 문서를 일일이 읽고 수동 링크해야 하는 작업. 실제 법률문서라 실명(윤연희·임건수)·실계좌가 정확 추출됨(시나리오 템플릿과 대조).

## 5. 결론

"폴더 전체 파이프라인"의 정답은 **형식 인지형 하이브리드**다. 비정형 트랙은 이미 구축·실증됐고, 핵심 가치(크로스-문서 자동 통합)가 실제 법률문서에서 입증됐다. 남은 것은 ① hwp 파서 ② MERGE 실적재 ③ 정형 ETL 연결 ④ anb 정답 대조 — 모두 **기존 자산 조립**이며 신규 설계는 없다.
