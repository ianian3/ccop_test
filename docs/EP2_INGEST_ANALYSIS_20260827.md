## 2. 수사 분석 — 6하원칙 (실측)

- **누가 (Who)**: 명의자 다수. **다계좌 보유 = 조직성**: 정진아·김경수·조지영 각 **3계좌**, 주다은·유경자·박지우 각 2계좌. (EP1의 단일 계좌 수렴과 달리, EP2는 명의자 1인이 여러 계좌 운용)
- **언제 (When)**: **2017-02-15 ~ 03-25** (약 40일) — EP1(3.10~15, 6일)보다 넓은 기간. 더치트로 과거 범행까지 소급 확장.
- **어디서 (Where)**: 네이버 중고나라. 자금 **7개 은행 분산**(기업·우리·국민·농협·하나·신한·광주) — EP1(3은행)보다 광범위.
- **무엇을 (What)**: 사기 **157건 / 편취금 총 9,628만원** (최대 250만원 · 평균 61만원).
- **어떻게 (How)**: 대포통장 29 · 전화 34(070 인터넷전화 14) · 계정 68 · **더치트 확장 링크 57**(계좌→전화→계좌 반복 검색 궤적).
- **왜 (Why)**: 더치트 반복 검색("추가 단서가 안 나올 때까지")으로 **단서망이 5개 계좌 → 29개 계좌로 확장**. 한 명의자가 여러 계좌를 운용하는 구조가 드러나 조직 규모 추정 가능.

## 4. 데이터 이슈·교훈

1. **컬럼 구조 차이 (002 vs 015)**: 002는 피해금 컬럼 있음(단서 col4+), 015는 없음(단서 col3+). thecheat 파서를 **헤더 기반 자동 매핑**으로 개선해 둘 다 대응. 데이터 행이 헤더를 오염시키던 문제도 헤더행 식별 로직으로 차단(EP1과 동일 교훈).
2. **비식별 불일치 지속**: EP2 명의자(정진아·김경수 등)는 EP1(이진아 등)과 다른 가명군. 같은 실사건군의 다른 비식별본일 가능성 — 통합 시 sameAs 검토 필요.
3. **숨김 시트**: 017은 11개 중 9개 숨김 — visible 필터로 `01_일람표`·`02_1-2차비교`만 대상.

  --xlsx "$D/017_..중복제거 작업(1-2차 비교)★_비식별화.xlsx" \
