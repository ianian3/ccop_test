## 2. 수사 분석 — 6하원칙 (실측)

- **누가 (Who)**: 070 명의자 17명(윤준호·이우성·김은혜 등). ★ **동일 IP 공유** = 인출책이 아닌 **운영 거점** 신호.
- **언제 (When)**: 2017-02~03 (통화·접속·거래 기간). EP1/EP2 신고기간과 겹침.
- **어디서 (Where)**: ★ **공유 접속 IP** — 070 명의가 IP별로 묶임:
  | 접속 IP | 070 명의 (공유) |
  |---|---|
  | **122.54.195.217** | 이우성·김은혜·추신수·이하성·최범근·김섭정 등 **7명** |
  | **122.54.197.65** | 권선미·차승재·손나연·박기선 등 |
  | 27.193.61.154 | 윤준호 |
  - 서로 다른 명의의 070이 하나의 IP에서 접속 = **같은 장소(콜센터)에서 다수 070 운용**.
- **무엇을 (What)**: 통화망 865건(contacted) + 자금흐름 58건 + 접속 15건.
- **어떻게 (How)**: 070 인터넷전화(발신지 은닉) + 카톡 대화 + 계좌 세탁. 역발신 회신으로 **070에 전화 건 발신자 45명** 확보.
- **왜 (Why)**: ★ **자금 종착 = 피어스미디어** — 계좌 17개가 `belongs_to` 피어스미디어. 김은희 계좌로 피어스미디어가 대규모 반복 송금(총 자금흐름 **6.6억원**). 팀미션 사기의 집금 조직 실체.

## 3. EP3의 수사적 전환점

EP1/EP2(신고·더치트)는 "누가 사기 쳤나(사건·대포통장)"였고, **EP3는 처음으로 통신(070·통화·카톡)과 자금(계좌이체)이 한 그래프에** 담김. 두 가지 결정적 단서:

1. **공유 IP → 콜센터**: 070 명의는 인출책이지만, 접속 IP가 겹치면 **실운영 거점**이 드러남 (EP6~7 "공유 IP → 사용자 특정"의 출발).
2. **피어스미디어 집금**: 흩어진 대포통장의 자금이 한 조직으로 수렴 → EP9-10 "조직 구조"의 근거.

즉 EP3는 **주범(Who) 추적의 열쇠**. 070 접속 IP와 자금 종착을 EP1/EP2 사건과 통합하면 "명의자 뒤의 실사용자"에 접근.

## 4. 데이터 이슈·교훈

1. **영장 회신 = 형식 폭발**: 한 EP에 docx·log·csv(euc-kr)·구형 xls·xlsx가 혼재 → 형식별 파서 필요(EP1/EP2의 요약 xlsx와 근본적으로 다름).
2. **카톡 로그 2형식**: 011은 대화 **내용** 형식(EP6~8의 접속 IP 형식과 다름). 기존 파서 오적재를 dry-run에서 차단, 대화 내용은 프라이버시로 **관계·빈도만** 적재.
3. **암호화 xls**: 수신거래내역 비밀번호 암호화 — 미적재.
4. **NFD 파일명**: macOS 한글 파일명 자모분리 → 정규식/NFC 정규화로 처리(070 번호 추출).
5. **비식별 명의 상이**: EP3 070 명의(이우성 등)는 EP1(이진아)·EP2(정진아 등)와 또 다름 — 통합 시 공유 계좌·IP·전화로 교차 연결됨.
