✓ 위치 기반 교차 분석: "강남역에서 같은 날 목격된 차량·전화번호" 단일 쿼리

POLE-E Event — 시공간 행위
vt_transfer 이체 vt_call 통화 vt_msg 메시지 vt_access 접속 vt_movement 이동이벤트 vt_lpr_evt vt_loc_evt vt_event (catch-all)
✓ vt_movement (통합): mov_type = lpr | cell_tower | transit_card — 3개 노드 → 1개
✓ 이벤트 노드의 timestamp가 Valid Time 담당 (이중시간 선택적 적용)
🟢 엣지 공통 속성: source_id (필수) + rec_created (필수) + confidence + verified
🟢 이중시간: valid_from/valid_to (소유 엣지) vs timestamp (이벤트 노드)
🟢 sameAs / contradicts 엣지: 동일 인물 다중 소스 병합, 모순 표시
🟢 경찰청 28개 표준 테이블 Coverage: 차량·위치·기관·이메일 도메인 추가
핵심 변경 포인트 상세

제거 / 통폐합

  • vt_inv — vt_case 속성(chrg_plcmn_nm, chrgdp_nm)으로 흡수
  • vt_event (catch-all) — 모호, 특화 이벤트 노드 사용
  • vt_persona — vt_id로 흡수·단순화
  • vt_assertion (v2안) — 엣지 속성으로 대체, 노드 불필요
  • vt_lpr_evt + vt_loc_evt → vt_movement(mov_type)로 통합
  • vt_bsst + vt_cctv → vt_loc(loc_type)로 통합
  • vt_psn.role 속성 — 엣지 타입으로 완전 이동
  • hash_md5 — MD5 충돌 취약, hash_val(SHA-256)으로 통일

신규 추가

  • vt_src — 출처 소스 노드 (Provenance 레이어)
  • vt_petition — 진정서 노드 (수사 개시 전 단계)
  • vt_id — 디지털 ID·닉네임 (플랫폼 계정)
  • vt_email — 이메일 주소 (경찰청 표준)
  • vt_movement — 이동 이벤트 통합 노드
  • Location Layer — 독립 레이어 신설
  • suspect_in / victim_in / witness_in — 역할 엣지 3개
  • sameAs / contradicts — 엔티티 해소 엣지

수정·보완

  • vt_bacnt — bank_cd 추가 (경찰청 복합 PK 정렬)
  • vt_telno — telco_nm, join_typ_cd, imsi 추가
  • vt_ip — is_tor, is_proxy, asn, abuse_score 추가
  • vt_site — url_addr 단일화, risk_grd, WHOIS 추가
  • vt_psn — POLE 4+1 (dob, gender, nationality, contact) 추가
  • vt_org — org_category, inst_se_cd, brno 추가
  • vt_loc — loc_type 속성 + 기지국·CCTV 속성 통합
  • EDGE 공통 — source_id + rec_created 의무화
역할 표현 방식 비교 (핵심 변경)
✗ 기존 방식 — Role을 노드 속성으로
vt_psn {role: "피의자"} → 노드 속성 ⚠ 덮어쓰기 위험
vt_psn {role: "피해자"} → 같은 노드에 저장 ⚠ 이전 역할 소실
홍길동이 사건 A에서 피의자, 사건 B에서 피해자인 경우
→ role 속성이 마지막 값으로 덮어씌워짐
✓ 개선 방식 — Role을 엣지 타입으로
vt_psn:홍길동 ─[suspect_in]→ vt_case:사건A
vt_psn:홍길동 ─[victim_in]→ vt_case:사건B
vt_psn:홍길동 ─[witness_in]→ vt_case:사건C
동일 인물이 여러 사건에서 서로 다른 역할 → 모두 독립 엣지로 보존

최종 엣지 메타속성 (EDGE_META_SCHEMA)
필수 source_id vt_src.src_id 참조
필수 rec_created DB 기록 시점 (Transaction Time)
필수 creation_method manual | etl | ocr_ner | osint | inference
권장 confidence 0.0~1.0
권장 verified false=주장 / true=검증완료
선택 valid_from / valid_to 소유·관계 엣지에만 (현실 유효기간)
조건부 verified_by / verified_at verified=true 시 필수
