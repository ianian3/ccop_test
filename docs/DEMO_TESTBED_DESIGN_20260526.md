## 1. 5계층 데모 시나리오 — "강남 보이스피싱 일당 추적"

수사관 관점의 단일 사건 종단 분석. 30분 데모.

### 시연 흐름

```
┌─────────────────────────────────────────────────────────────┐
│  Act 1: 외부 데이터 수집 → 표준화 RDB                          │
│  ─────────────────────────────────                          │
│  [00:00-05:00]                                              │
│  • CSV 업로드: 콜센터 통화 기록 100건                          │
│  • SOURCE_DOMAIN: "KICS" 라디오 선택                         │
│  • SOURCE_ID: "kics_evt_20260526"                          │
│  • ETL 진행 막대 → "X명 인물 / Y개 계좌 / Z건 통화 적재 완료"     │
│                                                             │
│  💡 시연 포인트:                                              │
│   - V4.0 메타 6컬럼 (id_format, source_domain,              │

│     자동 부착 강조                                            │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  Act 2: RDB 표준 데이터 → V4.0 온톨로지 그래프 변환             │
│  ─────────────────────────────────                          │
│  [05:00-10:00]                                              │
│  • [그래프 생성] 버튼 → RdbToGraphService.transfer_data       │
│  • 25 노드 라벨 / 55 엣지 자동 변환                             │
│  • V3.7 추론 후처리:                                          │
│    - pt_cluster 자동 생성 (TB_PETTN_CLSTR → 캠페인 군집)        │
│    - 중계기 탐지 (IMEI 공유 3대+ → vt_dev.dev_type=relay_station) │
│    - is_anonymous 마킹 (name NULL/익명 → true)               │
│  • "노드 N개 / 엣지 M개 / 추론 K건" 통계                        │
│                                                             │
│  💡 시연 포인트:                                              │
│   - 자동 추론 룰 4종 (SiteCluster/PtCluster/Relay/Anonymous)  │
│   - 도메인 정규화: RDB 'KICS' → 그래프 'investigation/T1'      │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  Act 3: 자연어 질의 → 시각화 — 수사관 인터뷰 시연                │
│  ─────────────────────────────────                          │
│  [10:00-22:00]                                              │
│  자연어 5종 시연:                                             │
│                                                             │
│  Q1) "강남 보이스피싱 일당의 피의자 보여줘"                       │
│      → CONTAINS '강남' + suspect_in                          │
│      → 6명 인물 노드 + 사건 연결                                │
│                                                             │
│  Q2) "피의자가 보유한 모든 계좌"                               │
│      → has_account 1-hop                                    │
│      → 25 계좌 노드 펼침                                       │
│                                                             │
│  Q3) "자금 흐름 추적"  [V4.0 워크플로 버튼]                     │
│      → fund_flow 워크플로 자동 실행                            │
│      → 30 이체 + 25 계좌 grid 시각화                          │
│                                                             │
│  Q4) "중계기 경유 전화 보여줘"                                  │

│  Q5) "OSINT 도메인 익명 인물 → KICS 동일인 매칭"                 │

│      → 4쌍 익명↔실명 연결 시각화                               │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  Act 4: 도메인 다양성 + 신뢰도 등급                            │
│  ─────────────────────────────────                          │
│  [22:00-27:00]                                              │
│  • 우상단 V4.0 툴바 → "cross_domain" 레이아웃 선택            │
│  • 그래프가 KICS / OSINT / DIGITAL / EXT 4 영역으로 분리       │
│  • 색상 표시: 각 도메인별 다른 톤                              │

│                                                             │
│  💡 시연 포인트:                                              │

                          ↓
┌─────────────────────────────────────────────────────────────┐
│  Act 5: Q&A 대비 + 통계 요약                                  │
```
