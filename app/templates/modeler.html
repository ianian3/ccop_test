          1
          그래프 이름 입력
          헤더 입력창
        

        

          
상단 입력창에 영문 그래프 이름을 입력합니다. 언더스코어(_)만 허용됩니다.

          
예) my_graph    ccop_2025    voice_phishing_v1

        

      


      
      

        

          2
          RDB 가져오기 → 노드 매핑
          테이블당 반복
        

        

          
헤더 "RDB 가져오기" 버튼 → 테이블 선택 → KICS 노드 타입 선택 → 컬럼 매핑 → "캔버스에 추가"

          

            

              
① 테이블 목록 조회

              
SELECT table_name, row_count
FROM information_schema.tables
WHERE table_schema = 'test_ccop'

            

            

              
② 컬럼 조회 (tb_prsn 예시)

              
SELECT column_name, data_type
FROM information_schema.columns
WHERE table_schema = 'test_ccop'
  AND table_name   = 'tb_prsn'

            

          

          

             캔버스에 추가까지 완료해야 데이터 적재 시 해당 테이블이 처리됩니다. 테이블 수만큼 반복하세요.
          

        

      


      
      

        

          3
          엣지(관계) 정의 + 조인 컬럼 설정
          관계당 반복
        

        

          
왼쪽 하단 "관계(엣지) 정의" 버튼 → Source/Target 노드 선택 → 관계 타입 입력 → 조인 컬럼 선택

          

            
조인 조건 예시 (인물 → 계좌: PRSN_ID 공유)

            

              vt_psn
              PRSN_ID
              =
              PRSN_ID
              vt_bacnt
              → has_account 엣지
            

          

          

             두 테이블에 같은 이름의 컬럼이 있으면 자동 추천됩니다.
          

        

      


      
      

        

          4
          그래프 생성 (스키마 DDL)
          헤더 "그래프 생성" 버튼
        

        

          
AgensGraph에 빈 그래프 틀(스키마)을 생성합니다. 데이터는 아직 없습니다.

          


-- 그래프 생성
CREATE GRAPH IF NOT EXISTS my_graph;
SET graph_path = my_graph;

-- 노드 라벨 생성 (캔버스에 추가한 노드마다)
CREATE VLABEL IF NOT EXISTS vt_psn;
CREATE VLABEL IF NOT EXISTS vt_bacnt;

-- 엣지 라벨 생성 (정의한 관계마다)
CREATE ELABEL IF NOT EXISTS has_account;
CREATE ELABEL IF NOT EXISTS owns_phone;

          

        

      


      
      

        

          5
          데이터 적재 (ETL)
          헤더 "데이터 적재" 버튼
        

        

          
RDB 테이블 데이터를 읽어 그래프 노드·엣지를 실제로 생성합니다. (노드 최대 5,000건/테이블, 엣지 최대 10,000건)

          

            

              
① RDB 읽기 → 노드 삽입 (tb_prsn 예시)

              
SELECT "PRSN_ID","KORN_FLNM","BRDT"
FROM test_ccop."tb_prsn" LIMIT 5000

→ 행마다:
SELECT * FROM cypher('my_graph', $$
  MERGE (n:vt_psn {prsn_id: '12345'})
  ON CREATE SET n = {prsn_id:'12345', name:'홍길동'}
  RETURN n
$$) AS (n agtype)

            

            

              
② RDB JOIN → 엣지 삽입 (has_account 예시)

              
SELECT DISTINCT s."PRSN_ID", t."PRSN_ID"
FROM test_ccop."tb_prsn" s
JOIN test_ccop."tb_fin_bacnt" t
  ON s."PRSN_ID" = t."PRSN_ID" LIMIT 10000

→ 쌍마다:
SELECT * FROM cypher('my_graph', $$
  MATCH (s:vt_psn {prsn_id:'12345'}),
        (t:vt_bacnt {actno:'110-1111-1111'})
  MERGE (s)-[r:has_account]->(t)
  RETURN r
$$) AS (r agtype)

            

          

          

             완료 후 자동으로 메인 화면으로 이동해 그래프 탐색이 가능합니다.
          

        

      


    


    

      
      
    

  







  

    
 스키마 템플릿 선택

    
범죄 유형별 기본 스키마를 불러옵니다. 현재 캔버스는 초기화됩니다.

    

    

      
    

  







  

    
 Graph Modeler 시작 가이드

    

      

        
1

        
팔레트에서 노드 추가
왼쪽 패널에서 KICS 표준 노드 타입을 클릭하면 캔버스에 추가됩니다.

      

      

        
2

        
관계(엣지) 정의
왼쪽 하단의 관계(엣지) 정의 버튼으로 노드 간 관계를 설정합니다.

      

      

        
3

        
Cypher 생성 / 그래프 생성
스키마 완성 후 상단 버튼으로 Cypher 코드를 확인하거나 AgensGraph에 직접 생성합니다.

      

      

        

        
자동 저장
작업 내용은 브라우저에 자동 저장됩니다. 열기 버튼으로 이전 작업을 불러올 수 있습니다.
